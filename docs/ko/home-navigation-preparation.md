# 홈 화면과 후속 탐색 준비 — 배포 전 기록

실제 DataLite 27 서버에서 인증된 브라우저로 읽기 요청과 화면 탐색만 측정했다. 채팅 전송이나 설정 변경은 하지 않았다. 비밀번호·인증 토큰·대화 본문·이미지 URL은 측정 결과에서 제외했다.

## 서버 측정

| 요청 | 첫 측정 | 다음 측정들 |
| --- | ---: | ---: |
| 전체 DB 통계 | 7,936ms | 2,329ms / 1,196ms |
| 파일 백업 목록 | 7ms | 약 7–10ms |
| 로그 200행 | 약 29ms | 약 10–11ms |

백업 화면도 디스크 경고용으로 전체 DB 통계를 요청했다. 전체 통계는 용량 합산 외에 미사용 청크, 보관 캐릭터 및 미디어 참조 검사까지 수행한다. 첫 전체 통계 요청의 정확한 내부 단계별 시간은 계측하지 않았으므로 모든 지연을 특정 검사 하나의 탓으로 단정하지 않는다. 로그와 백업 목록 API 자체는 이 측정에서 병목이 아니었다.

최근 대화 캐릭터를 열고 새로고침한 뒤 다시 여는 3회 측정에서 서버 이미지의 디스크 캐시 재사용이 확인됐다. 첫 두 회의 서버 이미지 8개는 모두 본문 전송 0바이트였다. 세 번째는 서버 이미지 10개 중 9개가 캐시였고, 이미지 전체 요청의 실제 전송 합계는 38,433바이트였다. 작은 앱 정적 이미지의 응답 헤더 전송도 합계에 포함된다. 새로 보인 이미지까지 이전에 다운로드한 것이라고 간주하지 않았다. 모든 캐릭터와 외부 이미지에 일반화할 수는 없다.

서버의 `/api/asset/` 경로와 클라이언트의 직접 이미지 URL을 확인했다. 현재 응답은 `max-age=31536000, immutable` 및 ETag를 사용한다. 같은 URL의 정상 캐시가 남아 있으면 이미지 본문을 다시 받을 필요가 없다. 따라서 이번 수정은 기존 이미지 캐시를 중복 구현하지 않는다.

## 로컬 수정

- 데스크톱 홈의 Recently Uploaded 위와 모바일 캐릭터 목록 위에 최근 캐릭터 최대 3개를 표시한다. 활동 메타데이터만 사용하며 휴지통 캐릭터를 제외하고 기존 최근 대화 숨김 설정을 존중한다.
- 첫 UI 프레임 이후 2.5초 뒤 설정 코드와 최근 대화의 브라우저 사본을 준비한다. 순차 최대 3개, 응답당 2MiB 제한, 전체 20초 제한을 적용한다. 절약 모드와 2G에서는 건너뛰고 사용자 입력이나 탭 숨김 시 대화 요청을 취소한다. 동적 코드 import 자체는 취소할 수 없다.
- 대화 준비는 현재 선택이나 활동 기록, DBState의 대화 본문을 바꾸지 않는다. 기존 IndexedDB 사본 저장 경로를 사용하며 실제 선택 시 서버의 변경분을 다시 검증한다. 첨부 이미지와 외부 이미지를 일괄 선다운로드하지 않는다.
- 대시보드 최초 조회는 기본 용량 통계만 읽고 정리 후보의 참조 검사를 생략한다. 생략한 결과는 0으로 확정하지 않고 미검사로 표시하며, 별도 ‘정리 대상 검사’ 버튼에서 전체 검사를 실행한다. 기본 조회에도 용량 합산과 파일 메타데이터 조회 비용은 남는다.
- 백업 화면과 시작 시 백업 안내는 디스크 용량과 백업 예상 크기만 조회한다. 전체 통계 및 정리 기능은 유지한다.
- `pocketrisu:startup:settings-prefetch`, `pocketrisu:startup:recent-chat-prefetch`를 추가했다. 첫 화면 비교는 기존 `navigation-to-ui-frame`을 사용하며 겹치는 단계 시간을 합산하지 않는다.

## 검증 및 남은 확인

관련 캐시·변경분·취소·저장소·시작 절차·서버 분기 테스트를 통과했다. Svelte 검사 오류 0개, 기존 접근성 경고 4개다. 별도 Vite 개발 화면과 실제 Chrome에서 1440px 및 390px 너비의 최근 카드 3개, 제목 위 배치, 클릭 경로, 가로 넘침 없음과 런타임 오류 없음을 확인했다. 모바일 전체 화면 통합 동작은 배포 후 추가 확인이 필요하다.

프로덕션 빌드와 배포는 실행하지 않았다. 수정 후 실제 서버의 메뉴 진입 시간 및 첫 화면 준비 시간 개선 폭은 아직 미측정이다. 배포 전 결과 보고 후 묶어서 빌드하고, 배포 뒤 홈 및 최근 캐릭터 경유 새로고침과 시스템 메뉴를 재측정해야 한다.
