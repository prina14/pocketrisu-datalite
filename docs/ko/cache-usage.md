# 캐시 사용량 표시 (`v1.17.0-datalite.6`)

메인 화면의 Recently Uploaded 위에 **이 기기의 캐시** 카드를 표시합니다.

브라우저가 저장 공간 추정 API를 제공하면 이 사이트의 사용량, 브라우저 저장 한도,
한도 내 남은 공간과 사용률을 보여 줍니다. 막대 색은 사용률에 따라 바뀝니다.
이 한도는 브라우저가 이 사이트에 할당하는 추정치이며 실제 기기 여유 공간이나
DB·플러그인 전송 캐시의 별도 512MiB 상한과 구분됩니다.

고정 IP의 HTTP 접속 등으로 해당 API를 사용할 수 없으면 저장된 채팅과 DB·플러그인
사본의 본문 크기를 집계해 추정 사용량만 표시합니다. 이미지·앱 파일의 HTTP 캐시는
이 대체 집계에 포함되지 않습니다. 알 수 없는 총량과 사용률을 임의로 표시하지 않습니다.

API 조회와 캐시 집계는 접속 단말에서 수행하며 서버 다운로드를 추가하지 않습니다.
HTTP 대체 집계는 최초 필요할 때 수행하고 수동 새로고침 전까지 결과를 재사용합니다.
화면을 벗어나면 진행 중인 집계를 취소합니다. 기존 채팅 본문을 실제로 읽는 최초·수동
집계의 비용은 남아 있으며, 크기 메타데이터만 합산하는 최적화는 별도 작업입니다.

이번 버전은 사용량 카드와 위 집계 동작을 추가합니다. 최적화 점검 보고서의 캐시 quota
처리, 메시지 ID 일치, Realm 자동 요청, 썸네일 등은 이번 릴리스에 일괄 적용하지 않습니다.
