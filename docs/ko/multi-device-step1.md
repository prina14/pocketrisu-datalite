# 기기 전환 개선 1단계: 서버 작업 안내

이번 변경은 **안내 표시 한 가지**만 추가합니다. 한 사용자가 PC와 모바일을 번갈아 쓰는 환경에서 단계별로 검증하기 위한 첫 단계입니다.

## 이번에 확인할 동작

- 서버에 작업으로 등록된 AI 응답 생성이나 저장 작업이 진행되면 화면 위에 **서버에서 작업 중입니다…**가 표시됩니다. 현재 기기와 다른 기기의 작업을 합친 상태입니다.
- 서버가 작업을 완료·실패·취소 상태로 바꾸면 작업 중 표시가 사라집니다. 이 표시가 사라진 것만으로 채팅 결과를 현재 화면에 반영했다는 뜻은 아닙니다.
- 상태 요청이 실패하거나 8초 동안 응답하지 않으면 **서버 작업 상태를 확인할 수 없습니다**로 바뀝니다. 안내가 입력이나 버튼을 막지는 않습니다.
- 일반 상태에서는 15초마다, 작업 중에는 5초마다 확인합니다. 숨겨진 탭에서는 중지하고 돌아올 때 즉시 확인합니다. 실패하면 30초 뒤 재시도합니다. 짧은 작업은 조회 사이에 끝나 표시되지 않을 수 있습니다.

상태 응답에는 생성 작업 수와 저장 중 여부만 있습니다. 채팅·DB 본문은 다운로드하지 않습니다. 서버의 모델 작업·로컬 스트리밍 프록시 작업·저장 작업을 관찰하며, 브라우저 안에서만 실행하는 플러그인이나 작업으로 등록되지 않는 직접 API 호출은 이 상태에 포함되지 않습니다.

## 다음 단계와 구분

이번 안내 기능은 저장권한을 획득·박탈하거나, 새로고침하거나, 채팅방을 이동시키거나, DB를 갱신하지 않습니다. **기존 프로그램의 저장권한 전환과 자동 재로딩 동작은 아직 그대로 있습니다.** 이 문제는 표시 기능을 확인한 뒤 별도 변경으로 다룰 예정입니다.

## 테스트

1. 서버를 새 소스로 빌드·실행하고 PC와 모바일에서 접속합니다.
2. PC에서 몇 초 이상 걸리는 AI 응답을 요청합니다. 모바일 화면에 안내가 나타나는지 확인합니다(최대 약 15초 지연).
3. 생성이 끝나거나 취소된 뒤 안내가 사라지는지 확인합니다(최대 약 5초 지연).
4. 모바일 연결을 끊어 상태 확인 불가 안내가 나타나는지, 다시 연결하면 정상 상태로 돌아오는지 확인합니다.
5. 안내 자체가 채팅 입력이나 화면 조작을 막지 않는지 확인합니다. 기존 기기 전환 재로딩은 이번 테스트에서 별개의 동작입니다.

설치는 [기존 업데이트 안내](data-lite.md#windows에서-기존-설치-업데이트)를 따릅니다. `save/`와 `backups/`는 보존합니다.
