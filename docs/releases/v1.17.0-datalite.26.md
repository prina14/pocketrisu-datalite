# DataLite 26 — 로딩 화면과 홈 화면의 안정적인 인계

- 로딩 화면부터 현재 빌드 버전을 표시합니다.
- 접속 통계와 후원 배너의 공간을 미리 확보해 응답 도착 시 아래 내용이 밀리지 않도록 합니다.
- 로딩 화면의 사이드바 폭·제목 위치·카드 테두리와 설명 너비를 실제 홈 화면에 맞춥니다.
- 최초 사이드바의 펼침 애니메이션을 생략하고 이후 사용자가 여닫는 애니메이션은 유지합니다.
- 앱의 초기 렌더링 기회에 맞춰 정적 로딩 화면을 해제합니다.

DB·인증·저장 형식과 플러그인 실행 순서는 변경하지 않습니다.

## 검증

관련 테스트 20개 통과, 타입 오류 0개(기존 접근성 경고 4개). 로컬 프로덕션 빌드와 실제 Node 서버·Chrome을 사용하는 합성 빈 DB 통합 시험에서 1440·1100·768px 데스크톱 UI의 제목 인계 및 지연된 통계·후원 표시 후 세로 이동 0px, 초기 사이드바 애니메이션 없음, 이후 열기·닫기 정상, 런타임 오류 0개를 확인했습니다.

로컬 빈 DB 시간은 실사용 서버의 성능 개선율을 뜻하지 않습니다. 실제 DB·플러그인·회선에서의 업데이트 후 측정은 별도로 진행합니다. 포터블은 GitHub Actions의 전체 검사·빌드·기동 시험을 통과한 뒤 게시됩니다.
