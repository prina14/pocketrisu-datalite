# DataLite 29 — 최근 대화 위치 고정과 로어북 재사용

- 홈 제목을 `Recent Chats`로 통일하고, 첫 HTML·로딩 미리보기·실제 최근 대화 영역에 같은 높이를 확보합니다. 카드가 나중에 채워져도 아래 내용이 밀리지 않습니다. 최근 대화 숨김 설정은 유지합니다.
- 캐시된 메시지뿐 아니라 로어북도 서버와 같은지 확인하고, 같으면 로어북 재전송을 생략합니다. 변경된 메시지·로어북·스크립트 변수는 계속 갱신합니다. 메시지가 없는 대화도 로어북을 재사용할 수 있습니다.
- 기존 서버·클라이언트와 호환되며 저장 데이터 변경이나 마이그레이션이 없습니다.

로컬 관련 테스트, 타입 검사와 Chrome 화면 검증을 통과했습니다. 1440px·390px 너비에서 로딩 전후 위치 변화 0px를 확인했습니다. 실제 브라우저 사본을 사용한 동일 Brotli 압축 비교에서 큰 로어북의 반복 응답 본문은 약 67.4kB→2.0kB, 51.1kB→2.0kB였습니다. 모든 대화의 응답이 같은 크기로 줄어드는 것은 아닙니다.
