# PocketRisu DataLite 12 — 캐릭터 미리보기·저장 초기화 최적화

인증과 최신 DB 읽기가 끝나면 플러그인·저장 준비를 기다리는 동안 캐릭터 이름을 먼저 표시합니다.
저장 기준 초기화의 보조 계산과 서버 DB 응답의 불필요한 전체 복사도 줄였습니다.

## 변경

- 휴지통을 제외한 실제 캐릭터 이름을 최대 40개 먼저 표시합니다. 추가 이미지 요청 없이 이름과 이니셜만 표시하며, 준비가 끝나면 기존 화면으로 전환합니다.
- 미리보기는 읽기 전용입니다. 채팅 전송·편집은 기존 초기화 완료 후 활성화하며, 인증과 계정 가져오기 차단 확인을 통과한 데이터만 표시합니다.
- 저장 기준의 독립 snapshot과 필수 해시는 초기화 때 준비하고, 변경 비교용 JSON 문자열·크기는 처음 필요할 때 계산합니다. 모듈 항목의 중복 해시도 줄였습니다.
- 서버 DB 읽기에서 인코딩 결과의 전체 복사를 줄이고, delta 패킷은 소유한 바이트 배열의 Buffer view로 전송합니다. 저장·백업 형식, delta 프로토콜과 무결성 검증은 유지합니다.
- `navigation-to-preview-frame`과 `preview-frame` 측정을 추가했습니다. 기존 `navigation-to-ui-frame`은 최종 화면 준비 측정으로 유지합니다.

## 효과와 절충

실제 Chromium의 약 10MB 합성 데이터 모듈 시험에서 저장 기준 초기화 중앙값은 **45.4 → 18.3ms**,
첫 저장은 **9.4 → 23.7ms**였습니다. 일부 보조 계산을 첫 저장·크기 조회로 옮긴 결과이며,
패치·예상 해시·저장 후 해시·추정 크기는 기존 구현과 일치했습니다.
이는 사용자 Oracle·Android 환경 전체의 개선율을 보장하는 수치는 아닙니다.

미리보기에는 화면을 그릴 기회를 주기 위해 보통 한두 프레임의 대기가 추가됩니다.
내용을 먼저 확인할 수 있게 하는 변경이며 총 초기화 시간이 항상 줄어드는 것은 아닙니다.
숨겨진 탭은 프레임 대기를 생략하고, 지연된 프레임에는 타이머 복귀 경로를 사용합니다.

## 검증·업데이트

앱 **1,827개**, 서버 **252개**, 호환성 **154개** 검사 통과. 앱 3개·호환성 6개 건너뜀.
타입 오류 0개, 기존 접근성 경고 4개입니다. 프로덕션 빌드와 실제 Node 서버·Chromium의
PC 첫 로그인·모바일 재접속에서 미리보기 선행 표시와 제거, DB delta 복원,
설정 열기·닫기를 확인했으며 런타임 예외는 없었습니다.
합성 테스트 DB와 외부 인터넷 요청을 차단한 환경의 검사입니다.

Linux x64 포터블과 SHA-256 파일을 제공합니다. 설치 서버에서 프런트엔드를 빌드할 필요 없이
기존 커스텀 자동 업데이트로 적용할 수 있습니다. 기존 설치 경로와 `save/`·`backups/`를 유지합니다.
