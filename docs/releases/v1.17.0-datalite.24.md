# PocketRisu DataLite 24 — 접속 시 불필요한 DB 메타데이터 갱신 줄이기

플러그인의 save storage 쓰기에서 이미 같은 소유자가 기록돼 있으면 메인 DB의 pluginStorageMeta를 다시 변경하지 않습니다. 실제 플러그인 값 쓰기는 유지하며, 새 키·소유자 변경·삭제 후 재기록은 반영합니다. save backend의 updatedAt은 소유권 변경 시각을 뜻합니다. local/idb backend 동작은 유지합니다.

진단에 plugin-storage-owner 이벤트를 추가했습니다. 플러그인 이름·backend·변경 여부만 기록하고 저장 키·값은 포함하지 않습니다.

## 검증

- 관련 모듈 5개 파일, 176개 테스트 통과(별도 최소 설정, happy-dom, 단일 threads 워커).
- Svelte/TypeScript 오류 0개, 기존 접근성 경고 4개.
- 수정 코드의 로컬 프로덕션 빌드, 사전 압축 표현 468개 원본 일치 및 초기 storage 의존 그래프 검사 통과.
- 릴리스 Actions는 전체 앱·서버 테스트, 타입 검사, 포터블 빌드 및 기동 검사를 별도로 수행합니다.

실서버 DataLite 23의 전경 새로고침 5회에서 navigation-to-ui-frame 중앙값 1.601초, 범위 1.431~2.654초를 관측했습니다. 캐시와 준비된 delta 재사용은 확인됐으며, 요청 대기의 편차는 아직 미해결입니다. 이번 수정본의 실서버 전후 개선율은 릴리스 준비 시점에 확인하지 않았습니다. 서로 겹치는 초기화 단계는 합산하지 않습니다.

기존 서버 자체 업데이트로 적용하는 Linux x64 포터블 릴리스입니다. 실제 플러그인 데이터 쓰기·사용자 설정·인증·revision 검사를 생략하지 않습니다.
