# DataLite 28 — 최근 캐릭터 홈 표시와 후속 화면 준비

- 홈의 Recently Uploaded 위에 최근 캐릭터 최대 3개를 표시합니다. 모바일은 캐릭터 목록 위에서 바로 열 수 있습니다. 휴지통 캐릭터를 제외하고 최근 대화 숨김 설정을 존중합니다.
- 첫 화면이 준비된 뒤 설정 코드를 미리 불러오고, 최근 대화 최대 3개의 브라우저 사본을 순차 준비합니다. 절약 모드·2G에서는 건너뛰며 사용자 입력이나 탭 숨김 시 대화 준비를 취소합니다. 대화 응답은 각각 2MiB 이하로 제한하고 첨부 이미지는 일괄 다운로드하지 않습니다. 실제 대화를 열 때는 서버 변경분을 다시 확인합니다.
- 대시보드의 기본 용량 조회와 미사용 미디어·청크 검사를 분리했습니다. 무거운 검사는 ‘정리 대상 검사’에서 실행하며 미검사 결과는 삭제 대상이 없는 것으로 확정하지 않습니다.
- 백업 화면과 접속 시 백업 안내는 디스크 용량과 예상 백업 크기만 조회하여 전체 DB 통계 검사를 피합니다.
- Proton Drive 클라이언트 버전 헤더에서 DataLite 접미사를 분리했습니다. 사용자 정의 버전 문자열 때문에 공유 링크 요청이 거절되던 문제를 수정합니다.

관련 캐시·변경분 재사용·취소·저장소·시작 절차 및 서버 분기 테스트를 로컬에서 통과했습니다. 최근 카드의 데스크톱/모바일 너비 배치와 클릭을 Chrome에서 확인했습니다. GitHub Actions에서 전체 검사, 빌드와 포터블 기동 시험을 수행한 뒤 게시합니다.

서버 DB·대화 본문·설정을 변경하는 마이그레이션은 없습니다. 기존 이미지 HTTP 캐시는 유지합니다. 배포 후 실제 서버에서 첫 화면 및 최근 캐릭터 경유 새로고침과 시스템 메뉴의 시간을 재측정합니다.
